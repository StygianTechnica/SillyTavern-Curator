Curator
While Curator controls the prompt, it changes every Chat Completion prompt SillyTavern builds with its prompt manager - including ones other extensions send for their own purposes, unless Only change chat replies is on. If another extension misbehaves, try that first, or switch control off.
Open Prompt Analyzer
Prompt Tester
Runs the compiled prompt against a SillyTavern connection profile in a sandbox - nothing reaches the chat or any other extension.
Test Prompt
Prompt Diagnostics
Ask a model about the current prompt - conflicts, ambiguities, ordering, token pressure. Uses the Prompt Tester's connection; a sandbox call.
Diagnose Prompt
Snapshots
Frozen copies of analysed prompts, for comparing later. Save one from the Prompt Analyzer; the 5 most recent are kept, oldest dropped first.
